# Ali Ahmad Rahmani — Engineering Portfolio v2

A custom React + Vite engineering portfolio focused on FPGA, DSP, real-time video processing and computer vision.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This repository is configured for GitHub Actions deployment. For a user site at
`https://<username>.github.io/`, Vite can use `/` as the base path. In GitHub:
Settings → Pages → Source → GitHub Actions.

Replace placeholder social/profile links in `src/main.jsx` with your exact URLs before publishing.
